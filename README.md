# LEIS Creator Visual Runtime Prototypes

Open `index.html` in a current desktop browser, then select a prototype:

- `hud.html` — WebGL-powered visual HUD with live pulse interaction.
- `scene.html` — Canvas spatial topology; move the pointer and select a node.
- `environment.html` — Combined command environment with an activation control.

The visual system encodes Core, Recovery, and Delta as active layers, and treats the lineage flow as the interface's operational path rather than decorative copy.

## Brand alignment

Restyled using `BRANDMANUAL_LEIS.md` as the governing source: deep blue for reality, gold for recognition and activation, white for understanding, gray for the unknown, and Ω for orientation. The copy and interaction model now prioritize relationships, lineage, movement, and reality-based validation.
